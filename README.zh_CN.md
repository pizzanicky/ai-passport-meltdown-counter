# 情绪崩溃计数器

## 简介

打工牛马每天的崩溃瞬间只有自己知道。

每天专注思考时有多少次被打扰？发表观点时有多少次被打断？怒气值爆表，压力无从发泄。

被干扰、被打断、情绪崩溃时都可以按一下确定键，为自己减压，记录每天的崩溃次数状态。

今日页看今天的次数，统计页看本周和较昨日，月历用颜色表示每一天的多少。

音效默认开启，长按确定键可以静音。

代码已开源，你也可以打造自己的解压神器。

## 使用说明

按一下确定键，记一次崩溃。显示次数并播放音效。上键看本周和较昨日，下键看本月。长按确定键静音，静音不影响计数。一分钟不操作息屏。

首次安装日期未确认时，需要用手机打开小程序「蓝牙配网-FoloToy AI PASSPORT」，选择 `BLUFI_FoloPassport`，填入 2.4 GHz Wi-Fi完成蓝牙配网。对时成功后即可使用。

蛋壳碎裂声的署名见 [assets/README.zh_CN.md](assets/README.zh_CN.md)。
