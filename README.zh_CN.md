# 情绪崩溃计数器

崩溃的时候按一下确定键。设备记下这一次，发出一声短促的声音，并显示今天的次数。统计页看这一周，月历看本月已经过去的每一天。

今日页按上键进入统计，按下键进入本月。统计页按下键回到今日。本月页按上键回到今日。到头不循环。在统计页或本月页短按确定键，也会记一次并回到今日。

统计页画出本周周一到周日的七根柱，以及较昨日的变化。暖色三角表示比昨天多，冷色三角表示比昨天少，旁边的数字是相差的次数。持平显示 0。昨天没有记录时，比较显示 `--`。

月历只显示当前这个月。每一天是一个方格，次数越多颜色越暖。今天多一圈轮廓。不属于本月的日子留空。

长按确定键切换静音。右上角的声音标记表示当前开还是关。静音时仍然计数，只是不发声。这个选择会保留。

第 1 到第 5 次播放短促的壳体破裂声。第 6 次起改为蛋壳碎裂声，并换掉还没播完的声音。新的一天从壳体破裂声重新开始，跨天本身不会自动出声。长按确定键、翻页、校时和恢复已保存的记录都不播放记录音。

日历使用北京时间，一周从周一开始。本次开机尚未确认日期时，屏幕写着日期未确认。这时短按确定键会先单独记下，并播放壳体破裂声，不会写入某一天。日期确认后，如果还有等待处理的次数，可以选择记入今日，或继续分开保存。在日期未确认的画面长按上键，会清除已保存的 Wi-Fi，并重新开始配网。

第一次校时：手机打开名为 **蓝牙配网-FoloToy AI PASSPORT** 的小程序，选择 `BLUFI_FoloPassport`，提供 2.4 GHz 的 Wi-Fi。校时完成后无线电关闭。屏幕上的时间只在本次开机完成校时之后才被采信。

屏幕上的次数显示到 `99999+` 为止，实际保存的次数可以继续增加。没有计时器、呼吸练习、排行、情绪标签或账号。

蛋壳碎裂声的署名见 [assets/README.zh_CN.md](assets/README.zh_CN.md)。准备提交到社区的字段，以及尚未完成的实机检查，见[发布草稿](docs/assets/community-release-draft.zh_CN.md)。
