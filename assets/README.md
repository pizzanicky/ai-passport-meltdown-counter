# Assets

This directory stores reusable fonts, images, music, and sound effects, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

The meltdown counter uses a 148-character subset, 12 px and 16 px, 1 bit per pixel, uncompressed LVGL format:

| File | Role |
| --- | --- |
| `fonts/NotoSansSC-Meltdown.ttf` | SIL Open Font License subset of Noto Sans SC. See `fonts/OFL-NotoSansSC.txt`. |
| `fonts/Rajdhani-Bold.ttf` | SIL Open Font License ASCII U+0020–U+007E. See `fonts/OFL-Rajdhani.txt`. macOS fonts are not packed. |
| `fonts/meltdown-glyphs.txt` | The CJK inventory merged with Rajdhani. |
| `fonts/meltdown_font_12.c`, `fonts/meltdown_font_16.c` | Generated sources compiled by `main/`. Symbols: `meltdown_font_12`, `meltdown_font_16`. |

Regenerate with `lv_font_conv` 1.5.3 after the glyph list changes. `tests/test_meltdown_assets.py` fails if a meltdown UI string uses a character missing from either size. The inventory has no em dash or fullwidth punctuation; the UI uses ASCII `-`, `,`, and `+`.

Store reusable source images and generated display assets in `images/`.

| File | Dimensions and format | Use and source |
| --- | --- | --- |
| [`images/home.jpg`](images/home.jpg) | 3840 × 2160, JPEG | Product hero image embedded in both project README files to foreground AI Passport and its open, maker-oriented identity. |

| [`images/logo-wordmark.png`](images/logo-wordmark.png) | 1648 × 336, PNG RGBA | Transparent black wordmark extracted from the repository's original `images/logo.png`; embedded in both project README files for light backgrounds. |

- Use descriptive names and document dimensions, pixel format, conversion steps, and destination.
- Prefer formats suitable for the 240 × 320 RGB565 display and account for Flash and internal RAM.
- Preserve editable sources where licensing permits, and record the source and license.
- Never commit device QR secrets, credentials, or personal data in images.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.

Meltdown counter clips are 16 kHz, 16-bit, mono PCM in flash. Playback uses `bsp_audio_write` at volume 70. That level is a size and loudness compromise and has not been measured on the speaker.

| File | Length | Use |
| --- | --- | --- |
| `music/meltdown_c3_pcm.c` | 35200 bytes, 1.10 s | Counts 1–5 after a trusted filing, and every press while the date is untrusted. Symbol `meltdown_c3_pcm`. |
| `music/meltdown_egg_pcm.c` | 28800 bytes, 0.90 s | Count 6 and above. Symbol `meltdown_egg_pcm`. |

`meltdown_c3_pcm.c` is the project casing-burst recording. `meltdown_egg_pcm.c` is a trimmed mix of two Freesound recordings. Keep this credit when publishing firmware that contains it:

1. DenseCrunch.wav by zimbot, Freesound 244485, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The mix trims, retimes, equalizes, and layers it.
2. egg - crack 01.wav by Anthousai, Freesound 336613, [CC0](https://creativecommons.org/publicdomain/zero/1.0/). The mix uses a filtered excerpt.

The editable masters and the rejected drafts stay in `plans/meltdown-counter/audio/` outside this repository. Mute, page changes, time sync, and restoring history do not play either clip. A new press replaces the clip already playing.

## Native mesh UI assets

`dots/meltdown_dots.c/.h` are generated by `node tools/gen_meltdown_dots.cjs`: grayscale A8 text/icon masks and a 24×24 RGB565 mesh tile. Chinese source: LVGL bundled Source Han Sans SC Normal, SIL OFL (see `fonts/OFL-SourceHanSansSC.txt`). Avenir Next Condensed and Menlo are local macOS rasterization references; their font files are not distributed. Small strokes retain grayscale coverage; large figures use an integral 3px lattice. No runtime font rasterizer is required. The earlier 1bpp font files remain legacy assets; the active UI uses these image masks.
